## Featured project

### Client Hub

My final-year graduation project, supported by research, requirements analysis, architecture documentation, and evaluation.

A shared client–freelancer workspace for projects, tasks, contextual discussions, and invoices. Optional extensions include human-reviewed PDF-to-task drafting, whole-invoice escrow, and audit-root anchoring.

| Component                 | Engineering focus                                                                                                               | Source                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Backend**         | Java 21 / Spring Boot modular monolith; project and invoice workflows, tenant-aware services, access policies, and audit trails | [Explore backend](https://github.com/Triet1705/client-hub-backend)     |
| **Web application** | Next.js / TypeScript dashboards for project work, tasks, invoices, and administration                                           | [Explore frontend](https://github.com/Triet1705/client-hub-frontend)   |
| **Smart contracts** | Solidity escrow and audit-anchor contracts, plus a work-certificate prototype, with TypeScript tests                            | [Explore contracts](https://github.com/Triet1705/client-hub-contracts) |

The backend separates domain, application, infrastructure, web, and Web3 concerns into Maven modules. The repositories include Maven verification, frontend build, and Hardhat CI workflows.
